# IamDejman/homebrew-tap

```bash
brew install iamdejman/tap/ai-wrapped-year
```

Then run `ai-wrapped-year`. Homebrew installs Node for it.

The formula follows the npm release of [ai-wrapped-year](https://github.com/IamDejman/ai-wrapped-year): a daily workflow moves it to the newest version once it installs and passes its test.
